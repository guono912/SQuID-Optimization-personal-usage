## Code Capabilities Added

The optimizer/backends now support several campaign-specific objectives and
guards:

- Mercier positivity and positive-margin penalties.
- DESC/VMEC ballooning lambda penalties.
- force-balance RMS penalty.
- high-|B| Boozer contour topology residuals.
- QSS coil proxy objectives for `Bn`, `K_rms`, and current-potential spectrum.
- boundary curvature / `pdrot` proxy.
- `iota_edge_mode` with target/upper/lower behavior.
- checkpoint and HTML checkpoint intervals.
- hard MHD gate penalties.

Treat optimizer penalties as steering only. Promotion still requires external
MHD gates and fixed-protocol coil review.

Important objective-policy update from 2026-06-15 discussion:

- Do not add objectives casually. Keep optimization stages minimal and make new
  terms earn their place through isolated tests or external gates first.
- ITG 95-percentile truncation was removed from
  `squid/objectives/itg_residual.py`; the ITG residual now integrates the bad
  curvature `xi` field directly instead of using `xi * max(xi_95 - xi, 0)`.
